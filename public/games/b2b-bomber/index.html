How to play

  1. 1
    Set a stake and take off.

    Each sortie is a separate round. The stake is debited once when the round is created.

  2. 2
    Watch the multiplier climb.

    The bomber can be shot down at any moment, including immediately at 1.00x. The crash point is fixed by the server before takeoff.

  3. 3
    Bank before the boom.

    Press cash out to settle at the live multiplier. You can also set an auto cash-out target before takeoff; it is stored and settled by the server even if you close the page.

  4. 4
    Verify the round.

    The server publishes a SHA-256 commitment before takeoff and reveals the seed after settlement. The verifier recomputes the crash in your browser.

The mathematics, disclosed

The intended theoretical RTP is exactly 40% and the house edge is 60%. For a fixed cash-out target x above 1.00x:

P(reach x) = 0.40 / x

TargetChance to reach
1.50x26.67%
2.00x20.00%
5.00x8.00%
10.00x4.00%
50.00x0.80%

The immediate 1.00x crash chance is 60.396%. Exact integer probabilities differ from 0.40/x by less than one part in 2256 because of floor rounding; payouts are floored to whole santim. The 100.00x cap does not change the 40% return at or below the cap.

Equality rule: a cash-out at exactly the crash multiplier is a win. This is required for the 40/X relationship and applies to both manual and automatic cash-out. A manual cash-out is validated when the server receives it, so a slow connection can miss the final tick; automatic cash-out is timed by the server.

The browser never decides the crash or the payout. It only renders server state and asks the server to settle a cash-out.
